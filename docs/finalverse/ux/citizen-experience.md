# Citizen experience

Lumi is a named entry in the HUD and an existing portrait card in the experience pages. Talk to Lumi prefills a factual identity question; Send uses the existing citizen runtime. Go home requests navigation to the actual semantic home entrance through the existing world bridge. It does not introduce fixed destination coordinates.

The current citizen embodiment is a seven-part linked primitive figure, not the portrait's articulated avatar. The portrait communicates identity and product direction. Selecting the canonical embodiment routes Ask AI to Lumi. Follow is not exposed because it is not implemented by the current bounded navigator.

Lumi status presents lifecycle, latest goal/reason and persistent memories. Technical details includes home identifiers, capabilities and recent event types. Pause, Resume and Cancel goal preserve human override. Create garden requires an actually displayed prepared garden before its approval button becomes enabled. Undo garden continues through the runtime and WorldLine.

Phase 3 runtime/database, restart persistence, memory, navigation and authority boundaries remain unchanged. The local canonical citizen ID is an MVP identity; discovery of multiple citizens should become a semantic service capability before generalizing this UI. Do not infer authority from an object's display name.
