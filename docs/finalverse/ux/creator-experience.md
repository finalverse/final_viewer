# Creator experience

Create provides three truthful starting points: A home for Lumi (existing bounded structure recipe), Lumi's garden (existing approved three-shrub recipe), and Describe a creation (existing supported WorldAction planner). A prompt that exceeds current capabilities must return clarification or an unsupported result, not simulated success. No category implies that furniture, cafés, arbitrary characters, or generated meshes already exist.

Selection exposes a small name card with Ask AI and Edit. Ask AI carries the viewer's actual selected root object into capability inspection; Edit opens the inherited build tools, with the command's existing permission callback. The preview's target and movement/dimensions help the user decide before approval. A changed selection requires a fresh plan.

Tools opens Objects & editing, Environment and Performance. Full interface restores inherited advanced menus, toolbars and panels. My Stuff opens the mature inventory rather than introducing a duplicate asset store. Undo and History are available in Finalverse AI. Existing copying/deletion limits and guarded compensation remain intact.

Finalverse Studio, Blender integration, mesh generation, publishing and marketplaces remain outside Phase 4A. The facade is a creation entry point, not a claim of unlimited natural-language world generation.
