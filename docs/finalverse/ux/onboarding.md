# Onboarding

The experience follows curiosity → beauty → emotional connection → interaction → creation → social connection → return. These are design goals; retention must be tested with people over time.

Start here opens a short welcome page. It teaches through three actions, rather than a mandatory tutorial: move with arrows/W/A/S/D, talk to Lumi, then review and approve a small creation. Explore opens inherited movement/camera tools if help is needed. Create and Friends are direct next steps. Taking a photo is under Explore.

| Target time | Experience | Current entry point |
|---|---|---|
| 0:00 | Enter MutSea Harbor | Existing grid login; region name in HUD |
| 0:30 | Move and look around | Start here, Explore, arrows/WASD, Alt camera |
| 1:00 | Identify Lumi | Lumi tab, named citizen portrait, world embodiment label |
| 2:00 | Ask a question | Talk to Lumi, Send |
| 3:00 | Propose a small change | Select → pick an owned object → Ask AI / Create garden |
| 4:00 | See the approved change | Plan preview, Apply / Create garden, Undo |
| 5:00 | Share the experience | Explore → Take a photo; Friends → Conversations |

These are product targets, not measured first-user results. Usability testing with new users remains necessary. Login still uses the existing grid/account flow; identity creation and invitation delivery are not newly implemented. The current local dev account is not a production signup service. Never commit its credentials or profile.

The moodboard's beauty belongs to later scene/asset work. This phase improves access to the living world without replacing rendering or pretending that the present primitive environment is the illustrated Harbor.
